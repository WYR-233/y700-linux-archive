# 功能现状（2026-10-13 结项时定稿）

状态记号：✅ 实测可用 · ⚠️ 能用但有明确缺陷 · ❌ 未打通

每一项都写了「怎么通的」和「还差什么」，方便判断今天重做时哪些可以直接复用。

---

## 1. 内核与引导

| 项 | 内容 |
| --- | --- |
| 内核 | Linux **7.2.7**（stable）+ [`GEEKiDoS/linux`](https://github.com/GEEKiDoS/linux) 分支 `v7.2-elden` 的约 150 个文件补丁（关键 commit `b0c05eb72`） |
| 配置 | `kernel/config/kernel-gpu.config`（327,346 B，完整 `.config`，**不是 defconfig**） |
| 编译 | `make ARCH=arm64 LLVM=-19 -j12 Image`（clang/lld 19） |
| 内嵌 | `CONFIG_BUILTIN_DTB=y` + `CONFIG_BUILTIN_DTB_NAME="qcom/sm8750-lenovo-elden"` + `CONFIG_CMDLINE_FORCE=y` + `CONFIG_INITRAMFS_SOURCE` |
| 产物 | `Image`（约 96 MiB 填满 `boot` 分区 100,663,296 B） |
| 引导 | ABL 直接引导内核，**没有 UEFI 环节**，所以 DTS 必须有 `chosen` 节点（`bootargs`） |
| 启动耗时 | 7.2 秒（内核 4.5 s + 用户态 2.7 s） |

**为什么是「完整 .config」而不是 defconfig**：当时走 defconfig + 手改 18 项的路，
产出的镜像根本起不来。官方答案是整份 `configs/kernel.config` + `LLVM=1` + 空 ramdisk + 内嵌 initramfs。

## 2. 显示 ✅

- 驱动：`msm_dpu` + 双 DSI bind，`msmdrmfb` → `fb0`
- 面板：CSOT，ABL 指定 `msm_drm.dsi_display0=qcom,mdss_dsi_elden_nt36523_csot_3k_dsc_vid`
- 现象：Console 119×95，屏幕亮
- 模式：24/40/60/90/120/144/165 Hz（社区 README 口径，本项目验证过 165 Hz 可用）

## 3. 触摸 ⚠️

- 官方 DT 里有**三套口径**：
  - `st,fts` / `st,fts2`（ST FingerTipS，i2c 0x49，走 QTS/Gunyah pvm）
  - `goodix,gt9916S`
  - 实机注册的是 **`NVTCapacitiveTouchScreen`**（Novatek）
- 本项目实测：**驱动注册成功、能点**，但主线缺 `novatek_ts_csot_3k_fw.bin` 固件，影响点按精度
- 社区 README 写的是「Touch: Working（Novatek NT36536）」
- **两种说法并存**：可能是社区换了 DTS 节点/补了固件，也可能是「能点」的标准不同。重做时需要实测确认

> 注意：`NT36536` 是**显示 DDIC**，不是触控 IC —— 这个误读当年纠正过一次。

## 4. Wi-Fi ✅

- 芯片：WCN7861（Peach），PCIe0 `17cb:110e`
- 上电链：`phy-qcom-pcie2` → `pci-pwrctrl-pwrseq` → rescan → `ath12k` → `wlan0`
- **真凶**：`CONFIG_PCI_PWRCTRL_PWRSEQ` 没加载 → 芯片没上电（dmesg 报 `Memory resource size exceeds max for 32 bits`）
- 服务：`y700-wifi`（轮询 PCI vendor `0x17cb` 出现 → insmod → 等 wlan0），开机自连
- **热点侧 MAC 拉黑**：能关联但拿不到 IP（DHCP 无 OFFER、ARP 5 发 0 回），换 MAC 立刻通。
  解：`nmcli con mod <SSID> 802-11-wireless.cloned-mac-address <MAC>`
- NetworkManager 插件属主坑：rootfs 重建后 `/usr/lib/.../NetworkManager/*/*.so` 属主变成 `y700`，
  NM 会 skip 并让 wlan0 变 `unmanaged` → `chown root:root` + `chmod 755`

## 5. 音频 ✅

- 硬件：**AW88461 ×2**（I²C `9-0034` / `9-0037`，Secondary MI2S），不是 WCD9378/WSA884X 直出
- 根因：缺 `/lib/firmware/qcom/sm8750/Lenovo-Y700-Gen4-tplg.bin`（AudioReach 拓扑）。
  `q6apm` probe 无条件 `request_firmware()`，失败即 `-ENOENT` → `ASoC error (-2)` → 声卡不出现
- 生成方法：
  ```bash
  git clone https://github.com/linux-msm/audioreach-topology
  m4 -I art topology.m4 > /tmp/topology.conf
  alsatplg -c /tmp/topology.conf -o Lenovo-Y700-Gen4-tplg.bin
  # sha256 必须是 33288df358504392dcc1d70ebdff4dc7a9ec8f9936edb30a65b3faa88a2000ef
  ```
- UCM2：`Qualcomm/sm8750/` 与 `conf.d/sm8750/` 拷到 `/usr/share/alsa/ucm2/`
- UCM 坑：`cset "name='SECONDARY_MI2S_RX Audio Mixer MultiMedia1' 1"` 是 pswitch（只亮左声道），改成 `on`/`off`
- 验证：`cat /proc/asound/cards` → `0 [LenovoY700Gen4]: sm8750 - Lenovo-Y700-Gen4`，左右喇叭都出声

## 8. 视频硬解（IRIS）✅

- 驱动：`iris` V4L2
- **关键开关 `CONFIG_SM_VIDEOCC_8750=y`**：少了它 videocc 不 probe → iris 拿不到 power-domain → `-110`
- 补丁：`kernel/patches/iris_*.c.patch` 只是加日志 + 把静默 break 改成返回 `-EINVAL`，方便定位上游固件静默失败
- 状态：能硬解；镜像 `boot-iris5.img` 未公开（构建产物）

## 9. GPU ✅

- Adreno 830，用户态打通
- 方案：Mesa 26 + backport；Qt 应用可跑
- 社区口径：Turnip + Zink
- 内核侧 GPU 供电链是本项目的主要贡献之一：`sm8750-lenovo-elden-gpu-power.dtsi`（S5D / S8I 轨）

## 10. USB ⚠️

- **Gadget（设备模式）✅**：复合设备 `0525:a4a7` = ACM 串口（`/dev/ttyGS0` → 主机 `/dev/ttyACM*`）+ RNDIS/ECM 网卡。
  主机侧 `70-y700-usb.rules` 给它稳定节点名 `/dev/ttyY700`、`/dev/y700-net`
- **主机模式（Host）⚠️**：`dr_mode=host` 重编 + FSA4480 mux 手动直通 →
  9008 长边口能挂拓展坞 + 2.4G 键鼠（**需拓展坞外接供电，VBUS 未解决**）
- **普通口（短边）❌**：GPIO29 实测不通；`PTN3222` eUSB2 通道未打通
- 补丁：`kernel/patches/drd.c.patch`（`dwc3_pre_set_role` 返回值检查 + GPIO 直通）

## 14. 电源 / 休眠 ❌

- 电源键：`logind` 里 `HandlePowerKey=suspend`，短按熄屏/挂起
- **Suspend 不可靠**：接 USB 睡眠会中止
- PMIC 长按约 7 秒硬件断电；插 USB 时秒级自动重上电
- 电池能充，但充电唤醒/上报有问题

## 15. init 与兜底

init（内嵌 initramfs）做三件事：

1. 挂 `userdata`（sda16，ext4）→ `switch_root`
2. 失败 → 从 `rawdump` 分区偏移 30 MB 的 `rootfs-offset.img` 起
3. 再失败 → 从 `lenovocust` 的 `/y700-rootfs.img` 起
4. **全失败就停在原地、不重启**（重启会扣 ABL 重试次数）

> 这个 init 脚本**没有归档**，是本仓库最大的复现缺口，见 `07-材料清单与复现缺口.md`。
