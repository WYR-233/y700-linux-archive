# 项目背景与时间线

## 一、为什么做

2026-09 拿到一台联想拯救者 Y700 四代（TB322FC）。想法很简单：
**把它变成一块跑原生 Linux 的平板** —— 不带 Android，开机直接进 Debian/Arch，
Wi-Fi、声音、屏幕、触屏都能用，最好还能当一台小服务器。

社区当时几乎没有这台机器的成熟方案（前代 Y700 有 `tb321fu-linux` 可参考，
更早还有 GEEKiDoS 对同 SoC 机型的实验）。于是从零开始摸。

## 三、结项时的判断

分两条线看：

- **「平板日常可用」✅ 达成**：原厂 358 + BL 锁定 + green + OTA 正常 + 序列号完好。
- **「自移植 Linux 主线」⛔ 归档**：功能面基本打通（GPU / 触摸 / 音频 / 相机 / 传感器 / 硬解 / USB host / Plasma Mobile），
  **卡在稳定性**。

三条理由：

1. **稳定性硬伤**：设备自行硬复位；Linux 从不向 ABL 报启动成功 → 开机 7 次扣光额度即卡 fastboot。
2. **取向变化**：主人原话「能用现成路径就用现成的，鼓捣得累了」。
3. **替代方案成熟**：社区移植包（ColorOS 16「近乎完美」/ 澎湃 OS 3）+ 官方 OTA 够用。
