# 硬件速查

> 全部来自「官方线刷包解包 + 设备端 dump + dmesg」的实测，不是猜的。
> 具体寄存器/引脚以你自己的设备 dump 为准。

## 一、平台

| 项 | 值 |
| --- | --- |
| 机型 | Legion Y700 Gen4，`TB322FC_PRC` |
| 代号 | `elden` |
| compatible | `lenovo,elden`, `qcom,sm8750` |
| 平台标识 | `qcom,sun` / `qcom,sunp`（实测 `SM8750P`，`hwid SM8750P_12+256_12`） |
| 出厂指纹 | `ZUXOS_1.5.10.229_260514_PRC`（结项时升到 `.358`） |
| 内存 | 约 11.7 GB（`Total DDR Size 0x2EAC60000`） |
| 存储 | UFS 三星 `KLUFG8RHKF-F0H1` 256 GB，6 LUN / 78 分区 |

## 二、外设节点

| 部件 | 节点 / 参数 |
| --- | --- |
| 屏幕 | CSOT 3K；ABL 指定 `msm_drm.dsi_display0=qcom,mdss_dsi_elden_nt36523_csot_3k_dsc_vid`；DPHY + DSC，165 Hz，支持笔 |
| 显示 IC | `NT36536`（**是 DDIC，不是触控 IC**） |
| 触摸 | 实机注册 `NVTCapacitiveTouchScreen`；官方 DT 另有 `st,fts`（i2c 0x49）/ `st,fts2` / `goodix,gt9916S` |
| Wi-Fi | WCN7861（Peach），PCIe0 `17cb:110e`；固件 `ath12k/PEACH/hw2.0/*` |
| 蓝牙 | 同芯片，UART14；`bt_rf_clk1`；固件 `brhbtfw20.tlv` + `brhbtnv20.bin` |
| 音频 | AW88461 ×2（i2c `9-0034` / `9-0037`，Secondary MI2S）；FM `rtc6226` |
| 振动 | AW86927 系 ×2 |
| 相机 | 后 `samsung,s5kjns` + VCM `giantec,gt9764`（cci0）；前 `galaxycore,gc08a8`（cci1）；相机 PMIC `willsemi,wl2868c`（i2c10） |
| USB | 两口：长边（9008 口，可 host）/ 短边（普通口）；eUSB2 `PTN3222`；role-mux `FSA4480`；普通口 `port-select-gpios` = GPIO29 |
| GPU | Adreno 830 |
| 视频 | IRIS（VPU35） |

## 三、分区（扇区 4096 B）

| 分区 | 用途 |
| --- | --- |
| `boot_a` / `boot_b` | 内核（96 MiB） |
| `init_boot_a/b` | 第一段 ramdisk（Android 13+ 的 init 在这，不在 boot） |
| `vendor_boot_a/b` | vendor ramdisk + dtb |
| `dtbo_a/b` | overlay dtb |
| `vbmeta_a/b` | AVB 链式元数据 |
| `recovery_a` | TWRP 测试通道 |
| `misc`（sda7） | BCB / A/B 元数据 |
| `userdata`（sda16） | 约 449 GB，Linux rootfs |
| `rawdump`（sda14，256 MB） | 内存转储区（头 2.26 MB 每次启动被重写），偏移 30 MB 放 rootfs 备份 |
| `lenovocust`（sda3，300 MB ext4） | 第二份 rootfs |
| `pstoredump`（sda15，128 MB） | 内核日志落盘（魔数 `Y700LINUXLOG`） |
| `super` | 原厂动态分区（odm/product/system/system_ext/vendor/vendor_dlkm） |
| `persist` | **传感器/相机校准，不可再生** |
| `proinfo` | 序列号 |
| `devinfo` | `ANDROID-BOOT!` + `01 01 01` |
| 引导链区 | sde 78 个 + sdb/sdc/sdd/sdf，**红线** |

产物 sha256 应为 `33288df358504392dcc1d70ebdff4dc7a9ec8f9936edb30a65b3faa88a2000ef`。

## 五、固件内嵌方式

内核配置里用 `CONFIG_EXTRA_FIRMWARE` 把固件直接编进 `Image`（当时选的路，因为 rootfs 早期没空间）：

```
CONFIG_EXTRA_FIRMWARE="... 按功能映射的文件名 ..."
CONFIG_EXTRA_FIRMWARE_DIR="/path/to/inputs/firmware"
```

注意 GEEKiDoS 的固件命名映射（`amss20.bin → amss.bin` 之类）当年踩过：
**用错版本会导致 MHI 握手 90 秒超时。**

## 六、串口 / 调试通道

| 通道 | 参数 |
| --- | --- |
| USB 复合 gadget | `0525:a4a7`，ACM 串口 + RNDIS/ECM |
| 主机侧稳定节点 | `/dev/ttyY700` → `/dev/ttyACM*`；`/dev/y700-net` → 网卡 ifindex |
| 设备侧 IP | `192.168.100.2/24`（USB 网卡），主机 `192.168.100.1/24` |
| 另一条 USB 网段 | 设备 `usb0 = 10.42.0.1/24` |
| 设备账号 | `root`（密码已不公开；当年是弱密码，重做时请改成密钥登录） |
| 进 fastboot | 拔 USB → 电源 + 音量下长按 20 秒 |
| 进 EDL | 关机 → 音量上 + 插线 |
